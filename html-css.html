1. 🌐 Introduction au développement web

Bienvenue dans le cours HTML & CSS de TAPHZI STACK. Tu vas apprendre les bases nécessaires pour créer tes propres pages web.

🧱 HTML

HTML signifie HyperText Markup Language.

Il sert principalement à organiser et structurer le contenu d'une page web.

🎨 CSS

CSS signifie Cascading Style Sheets.

CSS permet de modifier l'apparence de la page : couleurs, tailles, espacements, disposition, etc.

⚡ JavaScript

JavaScript permet notamment d'ajouter des interactions et des comportements dynamiques.

💻 Exemple 

<h1>Bienvenue sur TAPHZI STACK</h1>

<p>J'apprends le développement web.</p>

🧠 À retenir

HTML → structure

CSS → apparence

JavaScript → interactions

🧩 Petit exercice

Quelle technologie sert principalement à structurer une page web ?


2. 🏗️ La structure HTML

Une page HTML possède une structure de base. 

<!DOCTYPE html>

<html lang="fr">

<head>

    <meta charset="UTF-8">

    <title>Ma page</title>

</head>

<body>

    <h1>Bonjour !</h1>

    <p>Bienvenue sur ma page.</p>

</body>

</html>

🧠 Les éléments importants

<html> contient la page HTML.

<head> contient des informations sur la page.

<body> contient le contenu visible.

<title> définit le titre de la page dans l'onglet du navigateur.

🎯 À retenir

La structure HTML permet au navigateur de comprendre comment organiser la page.

3. 📝 Les titres et les textes

HTML possède différents éléments pour afficher des titres et des paragraphes. 

<h1>Grand titre</h1>

<h2>Sous-titre</h2>

<h3>Autre titre</h3>

<p>Voici un paragraphe.</p>

📚 Les titres

h1 correspond généralement au titre principal.

h2 et h3 servent à organiser les différentes parties du contenu.

✍️ Le paragraphe 

<p>
Bienvenue sur TAPHZI STACK.
J'apprends le HTML et le CSS.
</p>

🧩 Exercice

Quelle balise permet de créer un paragraphe ?


4. 🔗 Les liens et les images

🔗 Créer un lien

La balise <a> permet de créer un lien. 

<a href="https://example.com">
    Visiter le site
</a>

🖼️ Ajouter une image 

<img src="image.jpg"
     alt="Une image">

L'attribut src indique l'emplacement de l'image.

L'attribut alt fournit une description de l'image.

💡 Exemple complet 

<a href="https://example.com">

    <img src="image.jpg"
         alt="Mon image">

</a>

5. 🎨 Introduction au CSS

CSS permet de modifier l'apparence des éléments HTML.

💻 Exemple 

h1 {
    color: blue;
}

Ici, tous les éléments h1 deviennent bleus.

🔗 Relier CSS et HTML

Pour utiliser un fichier CSS externe : 

<link rel="stylesheet"
      href="style.css">

🧠 À retenir

HTML construit la structure. CSS personnalise l'apparence.

6. 🌈 Couleurs et tailles

CSS permet de contrôler les couleurs, les tailles et l'apparence du texte. 

h1 {
    color: blue;
    font-size: 40px;
}

p {
    color: gray;
}

🎨 color

La propriété color modifie la couleur du texte.

📏 font-size

La propriété font-size modifie la taille du texte.

📦 Exemple 

.titre {
    color: #2563eb;
    font-size: 32px;
}

🧩 Petit exercice

Quelle propriété permet de changer la taille du texte ?


7. 🔘 Créer et styliser un bouton

HTML permet de créer un bouton avec la balise <button>.

🧱 HTML 

<button>
    Commencer
</button>

🎨 CSS 

button {
    background: blue;
    color: white;
    padding: 12px 20px;
    border-radius: 8px;
    border: none;
}

🧠 Comprendre

background → couleur de fond

color → couleur du texte

padding → espace intérieur

border-radius → arrondit les coins

8. 🏆 Mini-projet : créer ta première page

Félicitations ! Tu arrives à la dernière leçon. Maintenant, tu vas créer une petite page web.

🎯 Objectif

Ta page doit contenir :

🏷️ Un titre
📝 Un paragraphe
🔘 Un bouton
🎨 Des couleurs personnalisées

💻 Code de départ 

<!DOCTYPE html>

<html lang="fr">

<head>

    <meta charset="UTF-8">

    <title>Mon site</title>

    <style>

        body {
            font-family: Arial;
            text-align: center;
        }

        h1 {
            color: blue;
        }

        button {
            background: blue;
            color: white;
            padding: 12px 20px;
            border: none;
            border-radius: 8px;
        }

    </style>

</head>

<body>

    <h1>Mon site</h1>

    <p>
        Bienvenue sur mon premier site !
    </p>

    <button>
        Commencer
    </button>

</body>

</html>

🚀 Ta mission

Personnalise ce projet avec ton propre titre, ton propre texte, tes couleurs et ton bouton.

🏆 Objectif final

À la fin de ce parcours, tu dois comprendre comment HTML structure une page et comment CSS permet de la personnaliser.
