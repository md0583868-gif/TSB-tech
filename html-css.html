1. 🌐 Introduction au développement web

Un site web utilise généralement plusieurs technologies pour fonctionner.

🌐 Les trois principales technologies

🧱 HTML → structure de la page

🎨 CSS → apparence et design

⚡ JavaScript → interactions

💻 Exemple HTML 

<h1>Bienvenue sur TAPHZI STACK</h1>

<p>Mon premier site web.</p>

🎯 À retenir

HTML construit la structure de la page. CSS permet de la rendre belle. JavaScript permet d'ajouter des interactions.

2. 🏗️ La structure HTML

Une page HTML possède une structure de base. 

<!DOCTYPE html>

<html lang="fr">

<head>

    <meta charset="UTF-8">

    <title>Ma page</title>

</head>

<body>

    <h1>Bonjour !</h1>

    <p>Bienvenue sur mon site.</p>

</body>

</html>

🧠 Comprendre

<html> contient toute la page.

<head> contient les informations de la page.

<body> contient ce qui est visible sur la page.

3. 📝 Les titres et les textes

HTML possède plusieurs niveaux de titres et permet d'écrire des paragraphes. 

<h1>Grand titre</h1>

<h2>Sous-titre</h2>

<h3>Petit titre</h3>

<p>
Voici un paragraphe.
</p>

🎯 Exemple

Le titre principal utilise généralement <h1>.

Les titres secondaires peuvent utiliser <h2> ou <h3>.

4. 🔗 Les liens et les images

HTML permet d'ajouter des liens et des images.

🔗 Créer un lien 

<a href="https://example.com">

    Visiter le site

</a>

🖼️ Ajouter une image 

<img
  src="image.jpg"
  alt="Mon image"
>

💡 À retenir

L'attribut href indique la destination d'un lien.

L'attribut src indique l'emplacement d'une image.

L'attribut alt décrit l'image.

5. 🎨 Introduction au CSS

CSS permet de modifier l'apparence des éléments HTML.

🎨 Exemple 

h1 {

    color: blue;

}

Ici, la couleur du titre devient bleue.

🧠 CSS signifie

Cascading Style Sheets, c'est-à-dire feuilles de style en cascade.

💻 Exemple HTML + CSS 

<h1 class="titre">
    Bienvenue
</h1>


.titre {

    color: blue;

}

6. 🎨 Couleurs et tailles

CSS permet de modifier les couleurs, les tailles et l'apparence du texte. 

h1 {

    color: blue;

    font-size: 40px;

}


p {

    color: gray;

}

📌 Les propriétés

color change la couleur.

font-size change la taille du texte.

background-color change la couleur de l'arrière-plan.

💻 Exemple 

body {

    background-color: black;

}


h1 {

    color: white;

    font-size: 40px;

}

7. 🔘 Créer un bouton

HTML permet de créer un bouton avec l'élément <button>. 

<button>

    Commencer

</button>

🎨 Ajouter du CSS 

button {

    background: blue;

    color: white;

    padding: 12px 20px;

    border: none;

    border-radius: 8px;

}

Avec CSS, tu peux modifier l'apparence du bouton.

8. 🏆 Mini-projet

Tu vas créer ta première petite page web.

💻 Code de départ 

<!DOCTYPE html>

<html lang="fr">

<head>

    <meta charset="UTF-8">

    <title>Mon site</title>

</head>

<body>

    <h1>Mon site</h1>

    <p>
        Bienvenue sur mon site !
    </p>

    <button>
        Commencer
    </button>

</body>

</html>

🎯 Mission

Personnalise la page avec :

• ton propre titre
• un paragraphe
• un bouton
• tes propres couleurs
• une image

🚀 Objectif

À la fin du projet, tu dois être capable de créer une petite page web avec HTML et de la personnaliser avec CSS.
