🌐 HTML & CSS

Apprends les bases de la création de sites web avec HTML et CSS.

📊 Ta progression HTML & CSS 0 / 10 leçons

🌐 Leçons

1. 🌐 Introduction au développement web

Un site web est généralement construit avec plusieurs technologies qui travaillent ensemble.

🧱 HTML

HTML permet de créer la structure de la page : titres, paragraphes, images, liens, boutons, etc.

🎨 CSS

CSS permet de modifier l'apparence de la page : couleurs, tailles, espacements, positions et animations.

⚡ JavaScript

JavaScript permet d'ajouter des interactions et des fonctionnalités dynamiques. 

HTML → Structure
CSS → Apparence
JavaScript → Interaction

2. 🏗️ La structure HTML

Une page HTML possède une structure de base. 

<!DOCTYPE html>

<html lang="fr">

<head>

  <meta charset="UTF-8">

  <title>Ma page</title>

</head>

<body>

  <h1>Bonjour !</h1>

</body>

</html>

🧠 À comprendre

<head> contient les informations générales de la page.

<body> contient les éléments visibles par l'utilisateur.

3. 📝 Les titres et les paragraphes

HTML possède plusieurs niveaux de titres. 

<h1>Grand titre</h1>

<h2>Sous-titre</h2>

<h3>Titre secondaire</h3>

<p>
Voici un paragraphe.
</p>

🎯 Exemple 

<h1>Bienvenue</h1>

<p>
Bienvenue sur mon premier site web.
</p>

4. 🔗 Les liens et les images

🔗 Créer un lien 

<a href="https://example.com">
  Visiter le site
</a>

🖼️ Ajouter une image 

<img
  src="image.jpg"
  alt="Mon image"
>

L'attribut href indique la destination d'un lien.

L'attribut src indique l'emplacement de l'image.

5. 📋 Listes et tableaux

📌 Liste 

<ul>

  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>

</ul>

📊 Tableau 

<table>

  <tr>
    <th>Nom</th>
    <th>Âge</th>
  </tr>

  <tr>
    <td>Ali</td>
    <td>20</td>
  </tr>

</table>

6. 🎨 Introduction au CSS

CSS signifie Cascading Style Sheets.

Il permet de contrôler l'apparence des éléments HTML. 

h1 {

  color: blue;

}

Ici, tous les titres h1 deviennent bleus.

🔗 Relier CSS à HTML 

<link
  rel="stylesheet"
  href="style.css"
>

7. 🎨 Couleurs et textes

CSS permet de modifier la couleur, la taille et le style du texte. 

h1 {

  color: #4da3ff;

  font-size: 40px;

}

p {

  color: gray;

  font-size: 18px;

}

📌 Propriétés importantes

  • color → couleur du texte
  • font-size → taille
  • font-weight → épaisseur
  • text-align → alignement

8. 📐 La mise en page

CSS permet de positionner les éléments d'une page.

📦 Flexbox 

.container {

  display: flex;

  justify-content: center;

  align-items: center;

  gap: 20px;

}

📱 Responsive

Le responsive design permet à un site de s'adapter aux téléphones, tablettes et ordinateurs.

9. ✨ Créer un bouton

HTML 

<button>
  Commencer
</button>

CSS 

button {

  background: #4da3ff;

  color: white;

  padding: 12px 20px;

  border: none;

  border-radius: 10px;

}

Tu peux ensuite ajouter des effets lorsque l'utilisateur passe la souris sur le bouton.

10. 🏆 Mini-projet

Tu vas maintenant créer une petite page web avec HTML et CSS.

💻 HTML 

<!DOCTYPE html>

<html lang="fr">

<head>

  <meta charset="UTF-8">

  <title>Mon site</title>

  <link
    rel="stylesheet"
    href="style.css"
  >

</head>

<body>

  <h1>
    Mon premier site
  </h1>

  <p>
    Bienvenue sur mon site !
  </p>

  <button>
    Commencer
  </button>

</body>

</html>

🎨 CSS 

body {

  background: #080b12;

  color: white;

  text-align: center;

  padding: 50px;

}

button {

  background: #4da3ff;

  color: white;

  padding: 12px 20px;

  border: none;

  border-radius: 10px;

}
