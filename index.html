1. Introduction à Python

Python est un langage de programmation simple et très utilisé.

🐍 Pourquoi apprendre Python ?

Python est utilisé pour créer des programmes, automatiser des tâches, développer des sites, analyser des données et bien plus encore.

💻 Premier programme 

print("Bonjour TAPHZI STACK")

La fonction print() permet d'afficher quelque chose à l'écran.

2. Les variables

Une variable permet de stocker une information. 

nom = "TAPHZI"
age = 20

print(nom)
print(age)

🧠 À retenir

Une variable possède un nom et contient une valeur.

3. Les types de données

Python possède différents types de données. 

nom = "Moustapha"
age = 20
taille = 1.75
majeur = True

📦 Quelques types

str → texte

int → nombre entier

float → nombre décimal

bool → vrai ou faux

4. Les conditions

Les conditions permettent à un programme de prendre des décisions. 

age = 18

if age >= 18:
    print("Tu peux continuer")
else:
    print("Tu dois attendre")

🧠 Mots importants

if signifie « si ».

else signifie « sinon ».

5. Les boucles

Les boucles permettent de répéter une action plusieurs fois. 

for i in range(5):
    print(i)

Cette boucle affiche les nombres de 0 à 4.

6. Les fonctions

Une fonction permet de regrouper des instructions que l'on peut réutiliser. 

def bonjour():
    print("Bonjour !")

bonjour()

🎯 Pourquoi utiliser une fonction ?

Les fonctions permettent d'organiser le code et d'éviter de répéter les mêmes instructions.

7. Les listes

Une liste permet de stocker plusieurs valeurs dans une seule variable. 

fruits = [
    "pomme",
    "banane",
    "orange"
]

print(fruits)

➕ Ajouter un élément 

fruits.append("mangue")

8. 🏆 Mini-projet Python

Pour terminer ton premier parcours, tu vas créer un petit programme.

💻 Projet 

nom = input("Quel est ton nom ? ")

print("Bienvenue", nom)
print("Bienvenue sur TAPHZI STACK !")

🎯 Mission

Essaie maintenant de modifier le programme pour demander également l'âge de l'utilisateur.
