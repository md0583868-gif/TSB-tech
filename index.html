1. Introduction à Python

Python est un langage de programmation très utilisé. Il permet notamment de créer des applications, automatiser des tâches et travailler avec les données.

Ton premier programme

print("Bienvenue sur TSB Tech !")

La fonction print() permet d'afficher du texte.

🧩 Exercice

Quelle commande permet d'afficher « Bonjour » ?

2. Les variables

Une variable permet de stocker une information. 

nom = "TSB Tech"
age = 20

print(nom)
print(age)

La valeur d'une variable peut être utilisée plus tard dans le programme.

🎯 Défi

Crée une variable appelée prenom et donne-lui ton prénom.

3. Les types de données

Python possède plusieurs types de données. 

nom = "Awa"       # texte
age = 20          # entier
taille = 1.75     # nombre décimal
connecte = True   # booléen

Les types courants sont str, int, float et bool.

4. Les conditions

Une condition permet à ton programme de prendre une décision. 

age = 18

if age >= 18:
    print("Majeur")
else:
    print("Mineur")

Python utilise if et else pour effectuer des choix.

5. Les boucles

Une boucle permet de répéter une instruction. 

for i in range(5):
    print(i)

Cette boucle affiche plusieurs valeurs automatiquement.

6. Les fonctions

Une fonction permet de regrouper des instructions que tu peux réutiliser. 

def saluer(nom):
    print("Bonjour", nom)

saluer("Awa")

7. Les listes

Une liste permet de stocker plusieurs éléments. 

fruits = ["mangue", "banane", "orange"]

print(fruits[0])

fruits.append("pomme")

8. 🏆 Mini-projet : calculatrice

print("Addition :", a + b)
