1. Introduction à Python

Python est un langage de programmation très utilisé pour créer des applications, automatiser des tâches et travailler avec les données.

Ton premier programme 

print("Bienvenue sur TSB Tech !")

La fonction print() permet d'afficher du texte.

🧩 Exercice

Quelle commande permet d'afficher « Bonjour » ?

2. Les variables

Une variable permet de stocker une information. 

nom = "TSB Tech"
age = 20

print(nom)
print(age)

🎯 Défi

Crée une variable appelée prenom et donne-lui ton prénom.

3. Les types de données

Python possède plusieurs types de données. 

nom = "Awa"
age = 20
taille = 1.75
connecte = True

Les types courants sont str, int, float et bool.

4. Les conditions

Une condition permet au programme de prendre une décision. 

age = 18

if age >= 18:
    print("Majeur")
else:
    print("Mineur")

5. Les boucles

Une boucle permet de répéter une instruction. 

for i in range(5):
    print(i)

6. Les fonctions

Une fonction permet de regrouper des instructions réutilisables. 

def saluer(nom):
    print("Bonjour", nom)

saluer("Awa")

7. Les listes

Une liste permet de stocker plusieurs éléments. 

fruits = ["mangue", "banane", "orange"]

print(fruits[0])

fruits.append("pomme")

8. 🏆 Mini-projet : calculatrice

Pour terminer ton premier parcours, crée une petite calculatrice Python. 

a = 10
b = 5

print("Addition :", a + b)
print("Soustraction :", a - b)
print("Multiplication :", a * b)
print("Division :", a / b)

🎯 Mission

Améliore ensuite le programme avec input() afin que l'utilisateur puisse entrer ses propres nombres.
