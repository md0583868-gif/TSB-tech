1. 🐍 Introduction à Python

Python est un langage de programmation simple, puissant et très utilisé.

💻 Premier programme

print("Bonjour TAPHZI STACK !")

La fonction print() permet d'afficher un message à l'écran.

🎯 Exercice

Quelle commande permet d'afficher « Bonjour » ?

2. 📦 Les variables

Une variable permet de stocker une information. 

nom = "TAPHZI"
age = 20

print(nom)
print(age)

🧠 À retenir

En Python, on peut créer une variable simplement en lui donnant une valeur.

🎯 Défi

Crée une variable appelée prenom.

3. 🔢 Les types de données

Python possède plusieurs types de données. 

nom = "Awa"

age = 20

taille = 1.75

majeur = True

str → texte

int → nombre entier

float → nombre décimal

bool → vrai ou faux

4. 🔀 Les conditions

Une condition permet à Python de prendre une décision. 

age = 18

if age >= 18:
    print("Majeur")
else:
    print("Mineur")

🧠 Comprendre

if signifie « si ».

else signifie « sinon ».

5. 🔁 Les boucles

Une boucle permet de répéter une instruction plusieurs fois. 

for i in range(5):
    print(i)

Ce programme affiche les nombres de 0 à 4.

🎯 Pourquoi utiliser une boucle ?

Elle évite de réécrire plusieurs fois la même instruction.

6. ⚙️ Les fonctions

Une fonction permet de regrouper des instructions réutilisables. 

def saluer(nom):
    print("Bonjour " + nom)

saluer("Awa")

def permet de créer une fonction.

7. 📋 Les listes

Une liste permet de stocker plusieurs valeurs. 

fruits = [
    "Pomme",
    "Banane",
    "Orange"
]

print(fruits[0])

Les éléments d'une liste commencent généralement à l'index 0.

8. 🏆 Mini-projet Python

Pour terminer ton parcours, crée un petit programme Python.

🎯 Mission

Crée un programme qui demande le prénom de l'utilisateur puis affiche un message. 

prenom = input("Ton prénom : ")

print("Bienvenue " + prenom + " !")

🚀 Objectif

Tu dois être capable d'utiliser des variables, une fonction d'affichage et une entrée utilisateur.
