1. 🐍 Introduction à Python

Python est un langage de programmation simple et très utilisé.

💻 Premier programme 

print("Bienvenue sur TAPHZI STACK !")

La fonction print() permet d'afficher un message.

2. 📦 Les variables

Une variable permet de stocker une information. 

nom = "TAPHZI"

age = 20

print(nom)

print(age)

🧠 À retenir

Une variable peut contenir du texte, un nombre ou d'autres données.

3. 🔢 Les types de données 

nom = "Awa"

age = 20

prix = 10.5

connecte = True

Python possède plusieurs types de données comme les chaînes de caractères, les nombres entiers, les nombres décimaux et les booléens.

4. 🔀 Les conditions

Les conditions permettent au programme de prendre des décisions. 

age = 18

if age >= 18:

    print("Majeur")

else:

    print("Mineur")

5. 🔁 Les boucles

Une boucle permet de répéter une instruction. 

for i in range(5):

    print(i)

Cette boucle affiche les nombres de 0 à 4.

6. ⚙️ Les fonctions

Une fonction permet de regrouper du code que l'on peut réutiliser. 

def saluer(nom):

    print("Bonjour " + nom)


saluer("Awa")

7. 📋 Les listes

Une liste permet de stocker plusieurs éléments dans une même variable. 

fruits = [
    "pomme",
    "banane",
    "orange"
]

print(fruits)

8. 🏆 Mini-projet Python

Crée un petit programme qui demande le prénom de l'utilisateur et lui souhaite la bienvenue. 

prenom = input("Quel est ton prénom ? ")

print("Bienvenue " + prenom + " !")

🎯 Mission

Modifie le programme pour ajouter ton propre message.
