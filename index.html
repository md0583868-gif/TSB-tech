1. 🖥️ Qu'est-ce que l'informatique ?

L'informatique est le domaine qui permet de traiter, stocker et transmettre des informations grâce aux ordinateurs et aux systèmes numériques.

💡 Exemple

Lorsque tu utilises un smartphone, une application ou un ordinateur, l'informatique intervient pour traiter les données.

2. 💻 Les composants

Un ordinateur possède plusieurs composants.

🧠 CPU → exécute les instructions.

💾 RAM → mémoire temporaire.

💽 Stockage → conserve les fichiers.

🖥️ Écran → affiche les informations.

3. 🧠 Le processeur

Le processeur, appelé CPU, exécute les instructions des programmes et effectue des calculs. 

CPU
 ↓
Exécute les instructions
 ↓
Produit un résultat

4. 💾 RAM et stockage

RAM

La RAM conserve temporairement les données utilisées par les programmes.

Stockage

Le stockage conserve les fichiers même lorsque l'appareil est éteint.

5. ⌨️ Les périphériques

Les périphériques permettent de communiquer avec un ordinateur.

⌨️ Clavier
🖱️ Souris
🎤 Microphone
🖥️ Écran
🔊 Haut-parleurs

6. 🌐 Internet

Internet est un vaste réseau permettant à des appareils de communiquer et d'échanger des données.

Le Web est un service qui fonctionne sur Internet et permet notamment de consulter des sites.

7. 🔐 Sécurité informatique

La sécurité informatique consiste à protéger les appareils, les comptes et les données.

🔑 Utilise des mots de passe solides.

🔒 Ne partage pas tes mots de passe.

🛡️ Active la double authentification.

⚠️ Fais attention aux liens suspects.

8. 🏆 Mini-projet

Trouve les caractéristiques de ton ordinateur :

🧠 Processeur
💾 RAM
💽 Stockage
🖥️ Système d'exploitation

📊 Progression Python 0 / 8

1. 🐍 Introduction à Python

Python est un langage de programmation connu pour sa syntaxe relativement simple.

Premier programme

print("Bonjour TAPHZI STACK !")

La fonction print() permet d'afficher une information.

2. 📦 Les variables

Une variable permet de stocker une information. 

nom = "TAPHZI"

age = 20

print(nom)

print(age)

Python permet de créer une variable sans indiquer explicitement son type.

3. 🔢 Les types de données

nom = "Moussa"

age = 20

taille = 1.75

connecte = True

Les données peuvent être de différents types : texte, entier, nombre décimal ou booléen.

4. 🔀 Les conditions

Une condition permet au programme de prendre une décision. 

age = 18

if age >= 18:

    print("Majeur")

else:

    print("Mineur")

5. 🔁 Les boucles

Une boucle permet de répéter des instructions. 

for i in range(5):

    print(i)

Ce programme affiche les nombres de 0 à 4.

6. ⚙️ Les fonctions

Une fonction regroupe des instructions qui peuvent être réutilisées. 

def saluer(nom):

    print("Bonjour", nom)


saluer("Moussa")

7. 📋 Les listes

Une liste permet de stocker plusieurs valeurs. 

fruits = [
    "pomme",
    "banane",
    "orange"
]

print(fruits)

On peut ensuite accéder aux éléments de la liste et les modifier.

8. 🏆 Mini-projet Python

Crée un petit programme qui demande le prénom de l'utilisateur et lui répond. 

prenom = input("Ton prénom : ")

print("Bonjour", prenom)

🎯 Mission

Modifie le programme pour afficher un message personnalisé.
