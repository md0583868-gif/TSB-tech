🐍 Python

1. Introduction à Python

Python est un langage de programmation simple, puissant et très utilisé.

🐍 Pourquoi apprendre Python ?

Python permet de créer des programmes, automatiser des tâches, travailler avec des données et développer de nombreux projets.

💻 Premier programme 

print("Bonjour TAPHZI STACK")

print() permet d'afficher un message.

2. Les variables

Une variable permet de stocker une information. 

nom = "TAPHZI"
age = 20

print(nom)
print(age)

Ici, nom contient du texte et age contient un nombre.

3. Les types de données

Python possède plusieurs types de données. 

nom = "Moustapha"
age = 20
taille = 1.75
majeur = True
  • str → texte
  • int → nombre entier
  • float → nombre décimal
  • bool → vrai ou faux

4. Les conditions

Une condition permet au programme de prendre une décision. 

age = 18

if age >= 18:
    print("Bienvenue")
else:
    print("Accès refusé")

if signifie « si » et else signifie « sinon ».

5. Les boucles

Une boucle permet de répéter une action. 

for i in range(5):
    print(i)

Le programme répète l'instruction plusieurs fois.

6. Les fonctions

Une fonction regroupe des instructions que l'on peut réutiliser. 

def bonjour():
    print("Bonjour !")

bonjour()

7. Les listes

Une liste permet de stocker plusieurs valeurs. 

fruits = [
    "pomme",
    "banane",
    "orange"
]

print(fruits)

On peut ajouter un élément avec : 

fruits.append("mangue")

8. 🏆 Mini-projet Python

Créons un petit programme qui demande le nom de l'utilisateur. 

nom = input("Quel est ton nom ? ")

print("Bienvenue", nom)
print("Bienvenue sur TAPHZI STACK !")

🎯 Mission

Modifie le programme pour demander également une autre information à l'utilisateur.
