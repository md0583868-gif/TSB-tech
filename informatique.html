💻 Bases de l'informatique

Découvre les fondamentaux de l'informatique et comprends comment fonctionne un ordinateur.

📚 Les leçons

📊 Ta progression 0 / 8

1. 🖥️ Qu'est-ce que l'informatique ?

L'informatique est le domaine qui permet de traiter, stocker et transmettre des informations grâce aux ordinateurs et aux systèmes numériques.

💡 Exemple

Lorsque tu écris un message, regardes une vidéo ou utilises une application, l'informatique intervient pour traiter les données.

🧠 À retenir

L'informatique permet notamment de manipuler des données et d'utiliser des programmes pour réaliser différentes tâches.

2. 💻 Les composants d'un ordinateur

Un ordinateur est composé de plusieurs éléments qui travaillent ensemble.

🧩 Les principaux composants

  • 🧠 Processeur (CPU) : exécute les instructions.
  • 💾 RAM : conserve temporairement les données utilisées.
  • 💽 Stockage : conserve les fichiers.
  • 🖥️ Écran : affiche les informations.

🎯 À retenir

Chaque composant possède un rôle différent, mais tous travaillent ensemble.

3. 🧠 Le processeur (CPU)

Le processeur, appelé CPU, est un élément essentiel d'un ordinateur.

⚡ Son rôle

Le CPU exécute les instructions des programmes et effectue des calculs.

💡 Exemple : lorsque tu ouvres une application, le processeur participe au traitement des instructions nécessaires à son fonctionnement.

🎯 À retenir

CPU = processeur = unité centrale de traitement.

4. 💾 RAM et stockage

🧠 La RAM

La mémoire RAM permet de conserver temporairement les données dont les programmes ont besoin.

💽 Le stockage

Le stockage permet de conserver les fichiers même lorsque l'ordinateur est éteint.

📸 Photos → stockage

🎮 Jeu ouvert → RAM utilisée

5. ⌨️ Les périphériques

Les périphériques sont des appareils connectés à un ordinateur pour permettre différentes fonctions.

⌨️ Périphériques d'entrée

Clavier, souris, microphone, caméra...

🖥️ Périphériques de sortie

Écran, haut-parleurs, imprimante...

💡 La souris permet d'envoyer des actions vers l'ordinateur.

6. 🌐 Internet et le Web

Internet est un vaste réseau qui relie des ordinateurs et des appareils dans le monde.

🌍 Internet

Il permet aux appareils de communiquer et d'échanger des données.

🌐 Le Web

Le Web est un service qui fonctionne sur Internet et permet notamment de consulter des pages et des sites web.

💡 Lorsque tu visites un site avec un navigateur, tu utilises le Web.

7. 🔐 Sécurité informatique

La sécurité informatique consiste à protéger les appareils, les comptes et les données.

🛡️ Bonnes pratiques

  • 🔑 Utiliser des mots de passe solides.
  • 🔒 Ne pas partager ses mots de passe.
  • 📱 Activer la double authentification lorsqu'elle est disponible.
  • ⚠️ Éviter les liens et fichiers suspects.

🎯 À retenir

La sécurité commence par de bonnes habitudes.

8. 🏆 Mini-projet

Pour terminer ce parcours, découvre les caractéristiques de ton appareil.

🎯 Mission

Essaie de trouver :

  • 🧠 Le modèle du processeur
  • 💾 La quantité de RAM
  • 💽 La capacité de stockage
  • 🖥️ Le système d'exploitation

💡 Objectif

À la fin de cette mission, tu dois être capable d'expliquer simplement à quoi servent les principaux composants de ton ordinateur.
