1. 🖥️ Qu'est-ce que l'informatique ?

L'informatique est le domaine qui permet de traiter, stocker et transmettre des informations grâce aux technologies numériques.

💡 Exemple

Lorsque tu utilises un téléphone, un ordinateur, une tablette ou une application, l'informatique intervient pour traiter les données.

🧠 À retenir

L'informatique permet notamment de manipuler des données et d'automatiser certaines tâches.

🧩 Petit exercice

Lequel utilise l'informatique ?

2. 💻 L'ordinateur

Un ordinateur est une machine électronique capable de recevoir, traiter et produire des informations.

🔄 Comment fonctionne-t-il ?

Un ordinateur reçoit des données, les traite puis produit un résultat. 

Entrée
   ↓
Traitement
   ↓
Sortie

💡 Exemple

Lorsque tu écris au clavier, l'ordinateur reçoit tes touches, les traite et les affiche sur l'écran.

3. 🧩 Les composants d'un ordinateur

Un ordinateur possède plusieurs composants qui travaillent ensemble.

🧠 Processeur

Le processeur exécute les instructions des programmes.

💾 RAM

La RAM conserve temporairement les données utilisées par les programmes.

💽 Stockage

Le stockage conserve les fichiers et les données de manière durable.

🖥️ Écran

L'écran affiche les informations à l'utilisateur.

4. 🧠 Le processeur CPU

Le CPU signifie Central Processing Unit, ou unité centrale de traitement.

⚡ Son rôle

Le processeur exécute les instructions nécessaires au fonctionnement des programmes.

💡 Exemple

Lorsque tu ouvres une application, le processeur traite les instructions nécessaires à son fonctionnement.

🎯 À retenir

CPU = processeur = unité centrale de traitement.

5. 💾 RAM et stockage

🧠 La RAM

La mémoire RAM est une mémoire temporaire. Elle permet aux programmes de travailler avec les données dont ils ont besoin.

💽 Le stockage

Le stockage conserve les données même lorsque l'appareil est éteint.

📌 Exemple

📸 Photos → stockage

🎮 Jeu ouvert → RAM utilisée

🧠 Question

6. ⚙️ Le système d'exploitation

Le système d'exploitation est le logiciel principal qui permet de gérer un appareil et ses ressources.

💻 Exemples

🪟 Windows

🍎 macOS

🐧 Linux

📱 Android

📱 iOS

🎯 Son rôle

Il permet notamment aux applications et à l'utilisateur d'utiliser le matériel de l'appareil.

7. 🌐 Internet

Internet est un immense réseau qui permet à des appareils de communiquer entre eux.

🌍 Internet et Web

Internet est l'infrastructure réseau.

Le Web est un service qui fonctionne sur Internet et permet notamment de consulter des sites et des pages web.

💡 Exemple

Lorsque tu ouvres un site avec un navigateur, tu utilises le Web.

🧠 Question

8. 🔐 Sécurité informatique

La sécurité informatique consiste à protéger les appareils, les comptes et les données.

🛡️ Bonnes pratiques

🔑 Utiliser des mots de passe solides.

🔒 Ne pas partager ses mots de passe.

📱 Activer la double authentification lorsqu'elle est disponible.

⚠️ Faire attention aux liens et fichiers suspects.

🔄 Garder ses logiciels à jour.

🎯 À retenir

La sécurité commence par de bonnes habitudes.
