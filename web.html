1. Introduction au développement web

Un site web utilise généralement plusieurs technologies.

Les trois principales

🧱 HTML → structure de la page
🎨 CSS → apparence de la page
⚡ JavaScript → interactions

Exemple

<h1>Bienvenue sur TSB Tech</h1>

2. La structure HTML

Une page HTML possède une structure de base. 

<!DOCTYPE html>

<html>

<head>
    <title>Ma page</title>
</head>

<body>
    <h1>Bonjour !</h1>
</body>

</html>

3. Les titres et les textes

HTML possède plusieurs niveaux de titres. 

<h1>Grand titre</h1>
<h2>Sous-titre</h2>
<h3>Petit titre</h3>

<p>Voici un paragraphe.</p>

4. Les liens et les images

Tu peux créer des liens et afficher des images. 

<a href="https://example.com">
    Visiter le site
</a>

<img src="image.jpg" alt="Mon image">

5. Introduction au CSS

CSS permet de modifier l'apparence de ta page. 

h1 {
    color: blue;
}

Ici, le titre devient bleu.

6. Couleurs et tailles

h1 {
    color: blue;
    font-size: 40px;
}

p {
    color: gray;
}

color change la couleur et font-size change la taille.

7. Créer un bouton

HTML permet de créer un bouton avec l'élément <button>. 

<button>
    Commencer
</button>

Ensuite, CSS peut rendre le bouton beaucoup plus beau.

8. 🏆 Mini-projet

Crée ta première petite page personnelle. 

<h1>Mon site</h1>

<p>
Bienvenue sur mon site !
</p>

<button>
Commencer
</button>

🎯 Mission

Personnalise la page avec ton propre titre, un paragraphe et un bouton.
