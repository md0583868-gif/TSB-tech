1. 🟨 Introduction à JavaScript

JavaScript est un langage de programmation très utilisé pour rendre les pages web interactives.

⚡ Premier exemple 

alert("Bienvenue sur TAPHZI STACK !");

La fonction alert() affiche un message à l'utilisateur.

🧩 Exercice

Quelle commande affiche une fenêtre avec le message « Bonjour » ?

2. 📦 Les variables

Une variable permet de stocker une information que ton programme peut utiliser. 

let nom = "TAPHZI STACK";

let age = 20;

console.log(nom);

console.log(age);

🧠 À retenir

let permet de créer une variable dont la valeur peut changer.

🎯 Défi

Crée une variable appelée prenom et donne-lui ton prénom.

3. 🔢 Types de données et opérateurs

JavaScript peut manipuler différents types de données. 

let nom = "Awa";

let age = 20;

let prix = 10.5;

let connecte = true;

➕ Les opérateurs 

let a = 10;

let b = 5;

console.log(a + b);

console.log(a - b);

console.log(a * b);

console.log(a / b);

Les opérateurs permettent notamment d'effectuer des calculs.

4. 🔀 Les conditions

Une condition permet au programme de prendre une décision. 

let age = 18;

if (age >= 18) {

    console.log("Majeur");

} else {

    console.log("Mineur");

}

🧠 Comprendre

Si la condition est vraie, le premier bloc est exécuté. Sinon, le bloc else est exécuté.

5. 🔁 Les boucles

Une boucle permet de répéter une instruction plusieurs fois. 

for (let i = 0; i < 5; i++) {

    console.log(i);

}

Cette boucle affiche les nombres de 0 à 4.

🎯 Pourquoi utiliser une boucle ?

Elle permet d'éviter de répéter manuellement le même code.

6. ⚙️ Les fonctions

Une fonction regroupe des instructions que tu peux réutiliser. 

function saluer(nom) {

    console.log("Bonjour " + nom);

}

saluer("Awa");

🧠 À retenir

Une fonction peut recevoir des informations appelées paramètres.

7. 🖱️ Les interactions

JavaScript peut réagir aux actions de l'utilisateur.

Exemple 

<button onclick="direBonjour()">

    Cliquez ici

</button>

<script>

function direBonjour() {

    alert("Bonjour !");

}

</script>

🎯 Mission

Imagine un bouton qui affiche un message lorsque l'utilisateur clique dessus.



8. 🏆 Mini-projet : page interactive

Pour terminer ton parcours JavaScript, tu vas créer une petite page interactive.

🎯 Objectif

Crée une page contenant :

🌐 Un titre
📝 Un texte
🖱️ Un bouton
⚡ Une interaction JavaScript

💻 Exemple 

function bienvenue() {

    alert("Bienvenue sur mon site !");

}

Ensuite, connecte cette fonction à un bouton HTML.
