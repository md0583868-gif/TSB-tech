1. ⚡ Introduction à JavaScript

JavaScript est un langage de programmation très utilisé dans le développement web.

Il permet notamment de rendre une page interactive et de réagir aux actions de l'utilisateur.

💻 Premier exemple 

alert("Bienvenue sur TAPHZI STACK !");

La fonction alert() affiche une boîte de dialogue dans le navigateur.

🧩 Exercice

Quelle instruction permet d'afficher un message ?


2. 📦 Les variables

Une variable permet de stocker une information que ton programme peut utiliser.

💻 Exemple 

let nom = "TAPHZI STACK";

let age = 20;

console.log(nom);

console.log(age);

🧠 Les mots-clés

let permet de créer une variable dont la valeur peut être modifiée.

const permet de déclarer une valeur qui ne doit pas être réassignée.

🎯 Défi

Crée une variable appelée prenom. 

let prenom = "Ton prénom";

3. 🔢 Types de données et opérateurs

JavaScript peut manipuler différents types de données.

📦 Exemples 

let nom = "Awa";

let age = 20;

let prix = 10.5;

let connecte = true;

🧠 Quelques types

String → texte

Number → nombre

Boolean → vrai ou faux

➕ Les opérateurs 

let a = 10;

let b = 5;

console.log(a + b);

console.log(a - b);

console.log(a * b);

console.log(a / b);

🧩 Exercice

Quel opérateur permet de multiplier deux nombres ?


4. 🔀 Les conditions

Une condition permet à un programme de prendre une décision.

💻 Exemple 

let age = 18;

if (age >= 18) {

    console.log("Majeur");

} else {

    console.log("Mineur");

}

🧠 Comprendre

Si la condition après if est vraie, le premier bloc est exécuté.

Sinon, le bloc else est exécuté.

🎯 Exemple 

let note = 15;

if (note >= 10) {

    console.log("Réussi");

} else {

    console.log("À revoir");

}

5. 🔁 Les boucles

Une boucle permet de répéter une instruction plusieurs fois.

💻 Exemple avec for 

for (let i = 0; i < 5; i++) {

    console.log(i);

}

Cette boucle affiche les nombres de 0 à 4.

🔁 Pourquoi utiliser une boucle ?

Une boucle évite d'écrire plusieurs fois la même instruction.

🧩 Petit exercice

Combien de fois cette boucle s'exécute-t-elle ? 

for (let i = 0; i < 3; i++) {

    console.log(i);

}

6. ⚙️ Les fonctions

Une fonction regroupe des instructions que tu peux réutiliser.

💻 Exemple 

function saluer(nom) {

    console.log("Bonjour " + nom);

}

saluer("Awa");

🧠 Comprendre

function permet de créer une fonction.

nom est un paramètre.

saluer("Awa") appelle la fonction.

🎯 Autre exemple 

function addition(a, b) {

    return a + b;

}

let resultat = addition(5, 3);

console.log(resultat);

7. 🖱️ Les interactions

JavaScript peut réagir aux actions effectuées par l'utilisateur.

💻 Exemple 

<button onclick="direBonjour()">
    Cliquez ici
</button>

<script>

function direBonjour() {

    alert("Bonjour !");

}

</script>

🧪 Tester

🎯 À retenir

JavaScript peut écouter les actions de l'utilisateur, comme un clic sur un bouton.


8. 🏆 Mini-projet JavaScript

Tu vas maintenant créer une petite page interactive.

🎯 Objectif

Crée une page contenant :

🌐 Un titre
📝 Un texte
🖱️ Un bouton
⚡ Une interaction JavaScript

💻 Exemple 

<button onclick="bienvenue()">
    Cliquez ici
</button>

<script>

function bienvenue() {

    alert("Bienvenue sur mon site !");

}

</script>

🚀 Mission

Personnalise le message et crée ta propre interaction.
