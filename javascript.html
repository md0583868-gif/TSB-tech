⚡ Leçons

1. ⚡ Introduction à JavaScript

JavaScript est un langage de programmation principalement utilisé pour rendre les pages web interactives.

🌐 HTML + CSS + JavaScript 

HTML
→ Structure

CSS
→ Design

JavaScript
→ Interaction

💻 Premier code 

console.log("Bonjour TAPHZI STACK !");

console.log() permet d'afficher une information dans la console.

2. 📦 Les variables

Une variable permet de stocker une valeur afin de pouvoir l'utiliser dans un programme. 

let nom = "Moussa";

let age = 20;

const pays = "Sénégal";

console.log(nom);

🧠 À retenir

  • let → variable pouvant changer
  • const → valeur constante

3. 🔤 Les types de données

JavaScript possède plusieurs types de données. 

let nom = "Ali";

let age = 20;

let prix = 15.5;

let actif = true;

📌 Principaux types

  • String → texte
  • Number → nombre
  • Boolean → vrai ou faux
  • Array → liste
  • Object → objet

4. 🔀 Les conditions

Les conditions permettent à un programme de prendre des décisions. 

let age = 20;

if (age >= 18) {

  console.log("Majeur");

} else {

  console.log("Mineur");

}

🧠 Principe

Si la condition est vraie, le premier bloc est exécuté. Sinon, le bloc else est exécuté.

5. 🔁 Les boucles

Les boucles permettent de répéter une instruction plusieurs fois. 

for (let i = 1; i <= 5; i++) {

  console.log(i);

}

Ce programme affiche les nombres de 1 à 5.

🔄 Exemple avec while 

let i = 0;

while (i < 5) {

  console.log(i);

  i++;

}

6. 🧩 Les fonctions

Une fonction est un bloc de code que l'on peut réutiliser. 

function direBonjour() {

  console.log("Bonjour !");

}

direBonjour();

📌 Avec un paramètre 

function saluer(nom) {

  console.log("Bonjour " + nom);

}

saluer("Ali");

7. 📋 Les tableaux

Un tableau permet de stocker plusieurs valeurs dans une même variable. 

let fruits = [
  "Pomme",
  "Banane",
  "Orange"
];

console.log(fruits[0]);

➕ Ajouter une valeur 

fruits.push("Mangue");

Les éléments d'un tableau commencent généralement à l'index 0.

8. 🧱 Les objets

Un objet permet de regrouper plusieurs informations liées entre elles. 

let personne = {

  nom: "Ali",

  age: 20,

  ville: "Dakar"

};

console.log(personne.nom);

🧠 À retenir

Les propriétés d'un objet permettent de décrire ses caractéristiques.

9. 🖱️ DOM et événements

JavaScript peut modifier les éléments HTML d'une page grâce au DOM.

💻 HTML 

<button id="monBouton">
  Cliquez-moi
</button>

⚡ JavaScript 

const bouton =
  document.getElementById("monBouton");

bouton.addEventListener(
  "click",
  function() {

    alert("Bonjour !");

  }
);

Ici, JavaScript détecte le clic sur le bouton et affiche un message.

10. 🏆 Mini-projet JavaScript

Pour terminer le parcours, crée une petite interaction avec JavaScript.

💻 Exemple 

<button
  onclick="bonjour()">

  Clique ici

</button>

<script>

function bonjour() {

  alert("Bienvenue sur TAPHZI STACK !");

}

</script>
